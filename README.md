# Save My Journey

다녀온 곳을 순서대로 남기는 여행 기록 앱.

사진과 그때의 감정, 시간과 위치를 한 곳에 모아 두고, 나중에 코스 전체를 한 장씩 넘겨보며 다시 걷습니다.

## 이런 걸 할 수 있어요

**날짜별로 기록해요**
하루에 여러 곳을 들렀다면 1일차 안에 나란히 담깁니다. 다음 날은 2일차로 이어집니다.

**사진과 감정을 같이 남겨요**
장소마다 사진과 영상을 붙이고, 그 자리에서 느낀 것을 그대로 적어 둡니다.

**지도 위에서 코스를 봐요**
들른 곳이 순서대로 이어진 선으로 그려지고, 실제 도로를 따라간 거리와 도보·차량 예상 시간을 알려줍니다.

**코스 종류를 나눠요**
여행 코스, 드라이브 코스, 산책 코스 중에 고르면 지도 위 선의 모양이 조금씩 달라집니다.

**한 장씩 넘겨보며 돌아봐요**
코스를 누르면 남긴 사진이 순서대로 한 화면씩 흐릅니다. 위로 밀면 다음 장소로 넘어갑니다.

**다른 사람의 코스를 찾아봐요**
완성한 코스를 공개하면 검색 탭에 올라가고, 다른 사람이 남긴 코스도 둘러볼 수 있습니다.

## 쓰는 법

홈 화면에 추가하면 앱처럼 열립니다. 탭은 좌우로 쓸어 넘기고, 목록을 아래로 당기면 새로고침됩니다. 코스를 길게 누르면 이름과 종류를 바꾸거나 지울 수 있습니다.

## 기록은 어디에 남나요

사진과 영상은 기기 안에만 저장됩니다. 다른 곳으로 올라가지 않고, 프로필 화면에서 통째로 내보내 보관할 수 있습니다.
